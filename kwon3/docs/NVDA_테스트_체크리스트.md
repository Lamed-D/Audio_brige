# VOICE BRIDGE NVDA 테스트 체크리스트

## 1. 준비

1. `npm run prepare:extension`을 실행한다.
2. `chrome://extensions`에서 기존 VOICE BRIDGE를 다시 로드한다.
3. `chrome://extensions/shortcuts`에서 네 단축키가 등록됐는지 확인한다.
4. NVDA를 실행하고 필요하면 `NVDA+N` 메뉴에서 `도구 > 음성 출력 뷰어`를 연다.
5. YouTube 영상 하나를 열고 재생한다.

## 2. Side Panel 탐색

1. `Alt+Shift+V`를 누른다.
2. NVDA가 `VOICE BRIDGE` 제목을 탐색할 수 있어야 한다.
3. `Tab`을 반복해 다음 순서로 이동한다.

`화면해설 사용` → `화면해설 음량` → `해설 중 원본 음량` → `긴 화면해설 재생 시 영상 자동 정지` → `조작 알림음` → `조작 알림음 음량` → `단축키·패널 음성 안내` → `현재 재생 시간 안내` → `진단 정보`

각 초점에서 NVDA가 이름, 컨트롤 종류와 현재 상태 또는 값을 읽어야 한다. Tab으로 이동할 때 짧은 초점음이 한 번 들려야 하며 컨트롤 이름을 VOICE BRIDGE가 별도로 반복해서 말하면 안 된다.

## 3. 컨트롤 피드백

- 체크박스에서 `Space`: NVDA가 체크 상태를 읽고, 켜짐은 상승음, 꺼짐은 하강음으로 구분돼야 한다.
- 슬라이더에서 방향키: NVDA가 변경된 퍼센트를 읽고, 값이 커질수록 알림음이 높아져야 한다.
- `조작 알림음`을 끈 뒤: NVDA 낭독은 유지되고 이후 초점·토글·슬라이더 음만 멈춰야 한다.
- `조작 알림음`을 다시 켤 때: 상승음이 한 번 들려야 한다.
- `조작 알림음 음량` 기본값은 80%이며 이전 버전보다 충분히 크게 들려야 한다.

## 4. 전역 단축키

| 단축키 | 기대 결과 |
| --- | --- |
| `Alt+Shift+V` | Side Panel이 열리고 자체 TTS가 패널이 열렸다고 안내한다. 다시 닫으면 닫혔다고 안내한다. |
| `Alt+Shift+S` | 미생성 영상이면 BE에 생성을 요청하고, 기존 작업이면 자체 TTS가 현재 단계·진행률·예상시간을 읽는다. |
| `Alt+Shift+J` | 자체 TTS가 재생 상태, 현재 시간, 남은 시간과 전체 길이를 한 번 읽는다. |
| `Alt+Shift+H` | 화면해설 상태가 바뀌고 자체 TTS가 `켰습니다` 또는 `껐습니다`를 한 번 읽는다. 영상에 아직 화면해설이 없어도 설정 상태는 바뀐다. |

단축키가 동작하지 않으면 `chrome://extensions/shortcuts`에서 다른 확장프로그램과의 충돌 및 지정 상태를 확인한다.

`Alt+Shift+T`는 Chrome 자체의 툴바 초점 이동 단축키이므로 테스트하지 않는다. `단축키·패널 음성 안내`를 끄면 자체 TTS가 멈추고 NVDA용 실시간 영역 안내가 동작해야 한다.

## 5. 오류와 중복 낭독

- YouTube가 아닌 탭에서 시간 안내를 실행하면 지원 영상을 찾지 못했다는 오류를 즉시 읽어야 한다.
- 영상 상태와 재생 위치가 1초마다 화면에서 바뀌어도 NVDA가 자동으로 반복 낭독하면 안 된다.
- 화면해설 음성이 재생될 때 `현재 해설` 문장을 NVDA가 다시 읽어 음성이 겹치면 안 된다.
- 해설 재생 오류는 낮은 오류음과 함께 한 번만 즉시 읽어야 한다.
- 생성 완료는 상승 완료음, 생성 실패는 낮은 오류음으로 구분돼야 한다.

## 6. 기록 항목

- Chrome 버전
- NVDA 버전과 음성 엔진
- 사용한 영상 URL
- 실패한 단계와 NVDA가 실제로 읽은 문장
- 단축키 충돌 여부
- 음량과 알림음이 영상 청취를 방해했는지 여부
