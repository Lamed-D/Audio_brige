# 들리는 화면 사용설명서

## 1. 필요한 프로그램

- Python 3.11 또는 3.12: [Python Windows 다운로드](https://www.python.org/downloads/windows/)
- FFmpeg와 FFprobe: [FFmpeg 다운로드](https://ffmpeg.org/download.html)
- OpenAI API 키: [OpenAI API 키 페이지](https://platform.openai.com/api-keys)

Windows에서는 FFmpeg를 다음 명령으로 설치할 수 있습니다.

```powershell
winget install --id Gyan.FFmpeg -e
```

설치 후 VS Code 터미널을 완전히 닫았다가 다시 열고 확인합니다.

```powershell
ffmpeg -version
ffprobe -version
```

## 5. 권장 사용 순서

1. `음성 인식 방식`은 기본값인 `OpenAI API (빠름)`을 사용합니다.
2. `최소 무발화 구간`은 2초로 둡니다.
3. `구간당 핵심 프레임`은 4장으로 둡니다.
4. `어려운 장면만 정밀 모델로 재분석`을 켭니다.
5. `TTS 및 접근성 영상 생성`을 켭니다.
6. 로컬 파일 또는 공개 영상 URL을 입력합니다.
7. `분석 시작`을 누르고 처리 로그를 확인합니다.

처리 중에는 다음과 같은 로그가 표시됩니다.

```text
영상에서 압축 음성 분석용 오디오를 추출합니다.
whisper-1 모델로 사람 발화 구간을 찾습니다.
유효 gap 12개를 찾았습니다.
후보 7장 중 핵심 4장만 선택했습니다.
Vision 분석을 최대 3개씩 병렬 처리합니다.
화면해설을 TTS로 병렬 생성합니다.
```

## 6. 속도 모드

가장 빠른 기본 설정은 다음과 같습니다.

```text
음성 인식: OpenAI API
최대 화면 분석 구간: 20
핵심 프레임: 4
동시 화면 분석: 3
빠른 Vision: gpt-4o-mini
정밀 Vision: gpt-4o, 어려운 장면만
```

처음 처리하는 URL은 다운로드 시간이 필요합니다. 같은 URL은 7일 동안 다운로드 캐시를 사용하고, 영상 내용과 STT 설정이 같으면 음성 전사도 재사용합니다.

API 사용량을 줄이려면 최대 화면 분석 구간 수를 낮추거나 정밀 모델 재분석을 끕니다. 정확도를 우선한다면 기본 설정을 유지합니다.

## 7. 자동 정확도 검증

결과의 `자동 검증` 필드는 다음 의미를 가집니다.

| 값 | 의미 |
|---|---|
| `passed` | 구조와 근거 검증 통과 |
| `rejected_unstable_ocr` | 같은 글자가 두 프레임 이상에서 확인되지 않음 |
| `rejected_uncertain_scene` | 장면 설명의 근거가 부족함 |
| `rejected_adjacent_duplicate` | 가까운 앞 구간과 유사한 해설임 |
| `narration_needs_tts_fit` | 문장이 길어 TTS 단계에서 속도를 맞춰야 함 |
| `analysis_error` | API 또는 응답 처리 오류 |

`source=skip`은 오류가 아니라, 틀린 정보를 읽지 않도록 해당 구간을 자동으로 건너뛴 결과일 수 있습니다.

## 8. TTS 길이 처리

해설 음성이 빈 구간보다 길면 다음 순서로 자동 처리합니다.

1. 원문을 TTS로 생성합니다.
2. 조금 길면 피치를 유지하면서 최대 1.5배까지 빠르게 만듭니다.
3. 많이 길면 문장을 짧게 만든 뒤 다시 생성합니다.
4. 그래도 맞지 않을 때만 제외합니다.

이전처럼 조금 길다는 이유만으로 모든 TTS가 사라지지 않습니다.

## 9. 결과 확인

- `speech.srt`: 영상의 말 자막
- `accessible.srt`: 말 자막과 화면해설을 합친 자막
- `script.json`: 구간별 OCR, 장면 설명, 자동 검증 결과
- `accessible_audio.m4a`: 화면해설이 합쳐진 소리
- `accessible_video.mp4`: 화면해설이 합쳐진 영상

웹 화면의 구간별 결과에서 어떤 프레임이 선택됐는지, 어떤 모델을 사용했는지, 왜 건너뛰었는지 확인할 수 있습니다.

## 10. 문제 해결

### FFmpeg/FFprobe가 없다고 나올 때

```powershell
winget install --id Gyan.FFmpeg -e
```

설치 후 터미널과 VS Code를 다시 시작합니다. 앱은 WinGet 기본 설치 위치도 자동으로 찾습니다.

### OpenAI 401 오류

`.env`의 API 키가 올바른지 확인합니다. 키를 새로 발급했다면 앱을 종료하고 다시 실행합니다.

### OpenAI 429 오류

계정의 사용 한도 또는 동시 요청 한도입니다. 잠시 후 다시 실행하거나 `동시 화면 분석 수`를 1~2로 낮춥니다.

### 유튜브 403 오류

다음 명령으로 yt-dlp를 업데이트합니다.

```powershell
.\.venv\Scripts\python.exe -m pip install --upgrade --pre "yt-dlp[default]"
```

그래도 실패하면 해당 영상이 로그인, 지역, 정책 또는 PO Token 제한을 받는 상태일 수 있습니다. 사용 권한이 있는 영상을 MP4로 준비해 파일 업로드를 이용합니다.

### 결과가 전부 skip일 때

자동 검증이 불확실한 설명을 제거한 것입니다. 정밀 모델 재분석을 켜고 핵심 프레임을 5~6장으로 올려 다시 시험할 수 있습니다.
