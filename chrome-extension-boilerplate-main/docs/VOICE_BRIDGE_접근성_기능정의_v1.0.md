# VOICE BRIDGE 접근성 기능정의 v1.0

## 1. 문서 정보

| 항목 | 내용 |
| --- | --- |
| 대상 버전 | VOICE BRIDGE FE `0.2.6` |
| 작성일 | 2026-08-18 |
| 대상 사용자 | 전맹·저시력 사용자, 키보드 사용자, 화면해설이 필요한 사용자 |
| 지원 환경 | Chrome 116 이상, YouTube, NVDA 기반 우선 검증 |

이 문서는 VOICE BRIDGE의 키보드 조작, NVDA 안내, 비언어 알림음과 오류 피드백 기준을 정의한다.

## 2. 설계 원칙

1. 컨트롤의 이름·역할·상태는 네이티브 HTML과 NVDA가 읽는다.
2. VOICE BRIDGE는 NVDA가 이미 읽는 내용을 별도 TTS로 반복하지 않는다.
3. 자주 발생하는 조작은 짧은 비언어 알림음으로 확인한다.
4. 단축키 결과와 패널 상태는 확장 자체 TTS로 우선 안내한다.
5. 자체 TTS가 꺼졌거나 실패했을 때 ARIA 실시간 영역을 폴백으로 사용한다.
6. 영상 재생 위치처럼 계속 변하는 값은 사용자가 요청했을 때만 읽는다.
7. 화면해설 TTS와 NVDA가 같은 문장을 동시에 읽지 않도록 현재 해설 본문은 자동 낭독하지 않는다.

## 3. 전역 단축키

| 단축키 | 기능 | NVDA 안내 |
| --- | --- | --- |
| `Alt+Shift+V` | VOICE BRIDGE Side Panel 열기·닫기 | 패널이 열렸는지 닫혔는지 자체 TTS로 안내 |
| `Alt+Shift+S` | 화면해설 생성 요청·상태 확인 | 미생성 영상은 BE 분석을 요청하고 기존 작업은 단계·진행률·예상시간을 자체 TTS로 읽음 |
| `Alt+Shift+J` | 영상 재생 위치 확인 | 재생 상태, 현재 시간, 남은 시간, 전체 길이를 자체 TTS로 한 번 읽음 |
| `Alt+Shift+H` | 화면해설 켜기·끄기 | 영상·매니페스트 유무와 관계없이 설정을 바꾸고 자체 TTS로 `화면해설을 켰습니다` 또는 `화면해설을 껐습니다` 안내 |

`Alt+Shift+T`, `Alt+Shift+A`, `Alt+Shift+I`, `Alt+Shift+N`은 Chrome 자체 기능과 겹치고 `Alt+Shift+R`은 NVIDIA 성능 오버레이와 겹치므로 사용하지 않는다. 재생 위치 안내는 `Alt+Shift+J`, 화면해설 토글은 `Alt+Shift+H`를 사용한다.

자체 TTS는 Windows의 한국어 시스템 음성을 사용하는 `chrome.tts`로 실행한다. `단축키·패널 음성 안내`가 꺼졌거나 TTS가 실패하면 활성 YouTube 페이지의 숨은 ARIA 실시간 영역으로 전달하고, 콘텐츠 스크립트가 없는 페이지에서는 Side Panel 영역으로 폴백한다.

단축키가 운영체제, NVDA 또는 다른 확장프로그램과 충돌하면 `chrome://extensions/shortcuts`에서 변경한다.

## 4. Side Panel 키보드 조작

| 키 | 동작 |
| --- | --- |
| `Tab` | 다음 조작 요소로 이동 |
| `Shift+Tab` | 이전 조작 요소로 이동 |
| `Space` | 체크박스 켜기·끄기, 진단 정보 펼치기·접기 |
| `Enter` | 버튼 실행, 진단 정보 펼치기·접기 |
| `←`·`↓` | 슬라이더 값 낮추기 |
| `→`·`↑` | 슬라이더 값 높이기 |
| `Home` | 슬라이더 최솟값으로 이동 |
| `End` | 슬라이더 최댓값으로 이동 |

기본 Tab 이동 순서는 다음과 같다.

`화면해설 사용` → `화면해설 음량` → `해설 중 원본 음량` → `긴 화면해설 재생 시 영상 자동 정지` → `조작 알림음` → `조작 알림음 음량` → `단축키·패널 음성 안내` → `현재 재생 시간 안내` → `진단 정보`

작업 생성·상태 확인 버튼이 표시되는 상황에서는 해당 버튼이 화면해설 설정 영역 안의 Tab 순서에 포함된다.

## 5. 비언어 알림음

알림음은 NVDA와 자체 TTS를 대체하지 않는다. 사용자가 방금 수행한 조작과 결과를 빠르게 구분하도록 돕는 보조 수단이다. 기본값은 켜짐, 음량은 80%이며 체크박스와 슬라이더로 조절한다.

| 상황 | 소리 형태 | 의미 |
| --- | --- | --- |
| Tab 초점 이동 | 짧은 단음 | 새 조작 요소에 초점이 도착함 |
| 슬라이더 조절 | 값에 따라 높아지는 짧은 단음 | 값의 증감 방향과 대략적인 수준 |
| 체크박스 켜기 | 낮은 음에서 높은 음으로 상승 | 기능이 켜짐 |
| 체크박스 끄기 | 높은 음에서 낮은 음으로 하강 | 기능이 꺼짐 |
| 일반 명령 실행 | 짧은 중간음 | 요청을 접수하거나 정보를 안내함 |
| 작업 완료 | 세 음이 순서대로 상승 | 화면해설 생성 또는 요청이 정상 완료됨 |
| 오류 | 낮은 두 음이 하강 | 재생·연결·생성 오류가 발생함 |

### 구현 기준값

| 소리 | 주파수와 길이 |
| --- | --- |
| 초점 | 720Hz, 28ms |
| 슬라이더 | 360~1080Hz, 34ms |
| 켜기 | 520Hz → 780Hz |
| 끄기 | 700Hz → 440Hz |
| 일반 명령 | 620Hz, 48ms |
| 완료 | 520Hz → 660Hz → 880Hz |
| 오류 | 260Hz → 210Hz |

피크 출력은 `0.18 × 사용자 음량`으로 계산한다. 기본 80%에서는 이전 구현보다 약 4배 큰 진폭으로 재생된다. 초점음과 슬라이더음은 빠르게 반복될 때 최소 간격을 적용해 소리가 겹치지 않게 한다.

## 6. NVDA 낭독 정책

### 네이티브 컨트롤

- 체크박스는 이름과 체크 상태를 NVDA가 직접 읽는다.
- 슬라이더는 이름과 `퍼센트` 단위의 현재 값을 NVDA가 직접 읽는다.
- 버튼은 화면에 표시된 명령명을 접근 가능한 이름으로 사용한다.
- 전역 단축키가 있는 컨트롤은 `aria-keyshortcuts`로 키 정보를 제공한다.

### 일반 안내

작업 시작, 생성 단계 변경, 25·50·75% 진행, 완료와 단축키 결과는 자체 TTS로 우선 안내한다. 자체 TTS가 비활성화됐거나 실행되지 않으면 `role="status"`, `aria-live="polite"`를 사용한다.

### 긴급 안내

음성 재생 실패, 네트워크 오류, 지원 영상 없음과 설정 변경 실패는 `role="alert"`, `aria-live="assertive"`로 즉시 안내한다. 같은 오류 상태가 계속 유지되더라도 반복해서 읽지 않는다.

### 자동 낭독하지 않는 정보

- 1초마다 갱신되는 영상 재생 위치
- 연결 상태와 진단 정보의 반복 렌더링
- 화면해설 TTS로 이미 재생 중인 `현재 해설` 문장
- 슬라이더 조작 시 별도의 중복 TTS 문장

## 7. 기능별 피드백

| 사용자 행동 또는 상태 | 화면 변화 | NVDA | 알림음 |
| --- | --- | --- | --- |
| Tab으로 컨트롤 이동 | 포커스 테두리 표시 | 이름·역할·값 읽음 | 초점음 |
| 화면해설 체크박스 변경 | 체크 상태 변경 | 체크됨·체크 안 됨 | 켜기·끄기음 |
| 음량 슬라이더 변경 | 퍼센트 변경 | 현재 퍼센트 읽음 | 값 연동 조절음 |
| 화면해설 만들기 | 생성 상태 표시 | 요청 및 주요 진행 단계 안내 | 명령음, 완료음 또는 오류음 |
| `Alt+Shift+J` | 위치 표시값 유지 | 자체 TTS로 현재·남은·전체 시간 안내 | 일반 명령음 |
| `Alt+Shift+H` | 체크 상태 동기화 | 켜짐·꺼짐 결과 안내 | 켜기·끄기음 |
| `Alt+Shift+V` 또는 패널 닫기 | Side Panel 표시 상태 변경 | 열림·닫힘 자체 TTS 안내 | 없음 |
| 해설 음성 재생 실패 | 오류 상태 표시 | 즉시 오류 안내 | 오류음 |
| 조작 알림음 끄기 | 체크 해제 | 체크 안 됨 | 끄기음 이후 음향 중지 |

## 8. 설정 저장

다음 설정은 `chrome.storage.local`에 저장되어 패널을 닫거나 Chrome을 다시 실행해도 유지된다.

- 화면해설 사용 여부
- 화면해설 음량
- 해설 중 원본 음량
- 긴 화면해설 자동 정지 여부
- 조작 알림음 사용 여부
- 조작 알림음 음량
- 단축키·패널 자체 TTS 사용 여부

조작 알림음을 꺼도 NVDA 낭독과 시각적 상태 표시는 유지된다.

## 9. 현재 한계와 주의사항

- VOICE BRIDGE는 NVDA 전용 애드온이 아니라 Chrome의 표준 접근성 트리를 사용한다.
- NVDA 설정, 음성 엔진, Chrome 버전에 따라 실제 발화 문구와 순서가 조금 달라질 수 있다.
- Chrome의 자동 재생 정책 때문에 페이지에서 첫 사용자 조작 전에는 첫 비언어 알림음이 지연될 수 있다. 이 경우에도 자체 TTS 또는 NVDA 텍스트 안내는 유지돼야 한다.
- 데스크톱 장치의 진동 지원이 일정하지 않아 진동 피드백은 구현하지 않는다.
- 확장 단축키는 다른 프로그램과 충돌할 수 있으며 사용자가 Chrome 단축키 설정에서 변경할 수 있다.
- Side Panel과 YouTube 본문 사이의 포커스 이동은 Chrome과 NVDA 조작 방식에 영향을 받을 수 있다.

## 10. 수용 기준

- 모든 주요 컨트롤을 마우스 없이 조작할 수 있다.
- NVDA가 각 컨트롤의 이름, 역할, 상태와 값을 구분해 읽는다.
- 반복 갱신 정보가 영상 시청 중 자동으로 계속 읽히지 않는다.
- 단축키와 패널 열림·닫힘 결과가 한 번만 읽히며 실제 상태와 일치한다.
- 초점·조절·켜기·끄기·완료·오류음이 청각적으로 구분된다.
- 알림음을 꺼도 핵심 정보가 NVDA와 화면 텍스트로 전달된다.
- 화면해설 TTS와 NVDA의 중복 발화가 발생하지 않는다.
- 오류 발생 후 영상 재생 상태와 원본 음량이 정상 복구된다.

수동 검증 절차는 [NVDA 테스트 체크리스트](NVDA_테스트_체크리스트.md)를 사용한다.
